# Генератор карточек Anki из Longman

[English](README.md) | [Русский](README.ru.md)

Небольшое настольное приложение, которое превращает список английских слов в
карточки Anki. Оно берёт первое предложение-пример из
[Longman Dictionary of Contemporary English](https://www.ldoceonline.com/),
заменяет целевое слово на `_____` и экспортирует текстовый файл с четырьмя
полями: **Front**, **Word**, **Back** и **Audio**.

Приложение написано на Python с интерфейсом на Tkinter и **не требует
сторонних библиотек** — `pip install` не нужен.

---

## Возможности

- Можно вставить сразу много слов: по одному в строке или через запятую /
  точку с запятой.
- Фильтр по части речи: существительное, глагол, прилагательное, наречие,
  фразовый глагол и т. д.
- Используется первое подходящее предложение-пример из выбранной статьи
  (первое, в котором действительно есть целевое слово).
- Учитываются словоформы: `colors`, `ran`, `studied`, `lighter`, а также
  словосочетания вроде `take off` и `take-off`.
- Понимаются определения вида **«the American spelling of colour»**:
  если на американской странице нет примеров, автоматически загружается
  британская страница, но ссылка в карточке остаётся на американское слово.
- В окне видны количество слов, прогресс и причина пропуска каждого слова.
- Запросы выполняются в фоновом потоке, поэтому интерфейс не зависает.
- Создаётся UTF-8-файл для импорта в Anki с кликабельными ссылками на Longman.
- Поле **Audio** экспортируется пустым, как и требовалось.

## Требования

- **Python 3.10 или новее**
- **Tkinter** (входит в стандартные установщики Windows и macOS; в Linux
  установите пакет `python3-tk`)
- Доступ в интернет к сайту `ldoceonline.com`

Сторонние Python-пакеты не нужны.

## Быстрый запуск

```bash
python app.py
```

В Windows также можно использовать:

```bash
py -3 app.py
```

Откроется окно с пустым списком слов. По умолчанию карточки сохраняются в:

```text
output/longman_cards_YYYYMMDD_HHMMSS.txt
```

## Как пользоваться

### 1. Введите слова

В большом текстовом поле можно использовать любой из вариантов:

```text
color
beautiful
take off
```

```text
apple, run; beautiful
```

- Слова разделяются переводами строк, запятыми и точками с запятой.
- **Пробелы не считаются разделителями**, поэтому словосочетания вроде
  `take off` остаются одним словом.
- Повторяющиеся слова игнорируются (без учёта регистра).
- Нумерация списка вида `1.` или `2)` удаляется автоматически.

### 2. Выберите часть речи

Используйте выпадающий список **Part of speech**:

- `Any` — берётся первая статья, у которой есть пример.
- `noun`, `verb`, `adjective`, `adverb`, `phrasal verb` и т. д. — поиск
  ограничивается этой частью речи.

Фильтр применяется и к статье Longman, и к британской странице, если
понадобился резервный вариант для американского написания.

### 3. Нажмите «Generate cards»

Кнопка **Generate cards** (или сочетание `Ctrl+Enter`) запускает генерацию.

В панели прогресса появляется каждая успешная карточка и каждое пропущенное
слово с объяснением. Если часть слов не удалось обработать, остальные всё
равно попадут в файл. Кнопка **Stop** останавливает работу после текущего
слова; уже созданные карточки сохраняются.

### 4. Импортируйте файл в Anki

1. В Anki создайте тип заметки ровно с четырьмя полями в таком порядке:

   | Поле | Содержимое |
   |---|---|
   | `Front` | Предложение с `_____` |
   | `Word` | Целевое слово |
   | `Back` | Ссылка на страницу Longman |
   | `Audio` | Всегда пусто |

2. Выберите **File → Import…** и укажите созданный `.txt`-файл.
3. Убедитесь, что разделитель — **Tab**, а параметр **Allow HTML in fields**
   включён.
4. Сопоставьте столбцы с полями и запустите импорт.

Файл начинается со служебных строк Anki:

```text
#separator:tab
#html:true
#deck:new
#columns:Front	Word	Back	Audio
```

Современные версии Anki используют `#columns` для автоматического
сопоставления полей. Старые версии считают эти строки комментариями и
попросят сопоставить поля вручную.

Поле `Back` содержит HTML-ссылку, например:

```html
<a href="https://www.ldoceonline.com/dictionary/color">https://www.ldoceonline.com/dictionary/color</a>
```

## Как работает парсер

1. Слово преобразуется в адрес страницы Longman:
   `color` → `https://www.ldoceonline.com/dictionary/color`,
   `take off` → `https://www.ldoceonline.com/dictionary/take-off`.
2. Страница разбирается встроенным модулем Python `html.parser` — браузер
   не используется.
3. Парсер идёт по основной колонке словаря и структуре
   `span.dictentry → span.assetlink → span.exaGroup`.
4. Нужная статья выбирается с учётом выбранной части речи.
5. Из основного `exaGroup` статьи извлекается первое предложение-пример,
   в котором есть целевое слово. Обычно это самая первая строка Longman;
   следующая берётся только в том случае, если в первой есть лишь производная
   форма (например, `walkers` для существительного `walk`).
6. Вхождения, отмеченные Longman (`span.NodeW`), и распространённые словоформы
   заменяются на `_____`.
7. Для определений вида **«the American spelling of [британское слово]»**:
   - если на американской странице есть пример, используется он;
   - если примера нет, загружается страница британского слова, берётся её
     первый пример, и британское написание тоже заменяется на `_____`.
8. Поле `Back` всегда ссылается на страницу словаря для того слова, которое
   ввёл пользователь.

Приложение делает запросы аккуратно: между загрузками страниц есть небольшая
пауза, ответы кэшируются на время сеанса, а неудачные запросы повторяются
несколько раз.

## Ограничения и примечания

- Longman может в любой момент изменить HTML; парсер рассчитан на структуру,
  описанную выше.
- У некоторых слов в основном блоке примеров нет примеров. Такие слова
  помечаются как пропущенные, чтобы не создавать некорректную карточку.
- Первый пример иногда оказывается диалогом или фрагментом — это всё равно
  первый пример, который предоставляет Longman.
- Сетевые ошибки, ограничение частоты запросов или региональная блокировка
  могут помешать загрузке. Для каждого пропущенного слова показывается причина.
- Инструмент предназначен для личного и учебного использования. Соблюдайте
  условия сайта Longman и не распространяйте скопированные материалы.

## Решение проблем

| Проблема | Решение |
|---|---|
| `ModuleNotFoundError: No module named 'tkinter'` | Установите Tkinter (`sudo apt install python3-tk` в Debian/Ubuntu или используйте стандартный установщик Python для Windows/macOS). |
| «Could not reach the Longman Dictionary» | Проверьте интернет и повторите попытку; Longman иногда блокирует или замедляет запросы. |
| «has no … entry» | Выберите `Any` или часть речи из списка, указанного в сообщении. |
| «No example sentence was found» | У этой статьи Longman нет примера из корпуса; попробуйте другую часть речи или пропустите слово. |
| Файл создан, но Anki показывает один столбец | Включите разделитель Tab и HTML в диалоге импорта, затем сопоставьте четыре поля. |
| Некоторые слова пропущены | Посмотрите красные строки в панели прогресса — там указана причина. |
